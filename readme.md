# Операционные системы

Учебно-методические материалы по дисциплине **«Операционные системы»** для студентов второго курса.

Репозиторий объединяет рабочие программы, лекционные материалы, практические работы и задания для контрольных работ по трём направлениям подготовки.

## Структура материалов

В каталоге каждого направления предусмотрены следующие разделы:

- **Лекции** — конспекты, учебные схемы и иллюстрации;

## Основные темы курса

Материалы охватывают:

- архитектуру ОС и границы доверия;
- процессы, потоки, планирование и системные вызовы;
- синхронизацию и межпроцессное взаимодействие;
- виртуальную память и механизмы противодействия эксплуатации;
- файловые системы, устройства и драйверы;
- пользователей, группы, PAM и делегирование полномочий;
- DAC, ACL, RBAC и мандатное разграничение доступа;
- безопасность Astra Linux;
- службы, сетевую конфигурацию и межсетевое экранирование;
- обновления, журналирование, аудит и контроль целостности;
- виртуализацию, контейнеры, реагирование и восстановление.

## Как пользоваться репозиторием

1. Выберите своё направление подготовки.
2. Откройте нужный раздел: лекции, практики, контрольные работы или РПД.
3. Для просмотра материала на GitHub откройте соответствующий файл `.md`.
4. Изображения, используемые в лекциях и практических работах, находятся в соседних каталогах `images`.
5. При выполнении практических заданий соблюдайте ограничения, указанные в методических материалах.

> Все действия, связанные с настройкой, диагностикой или проверкой безопасности, должны выполняться только в разрешённой учебной среде. Запрещается воздействовать на сторонние системы и сети.

## Форматы файлов

- `.md` — тексты лекций, практических работ и методические материалы;
- `.png` — учебные схемы и иллюстрации.
