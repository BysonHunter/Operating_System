# Проверка и адаптация практической работы № 7

Дата: 25 октября 2026 года. Итог: основная методика совместима с предоставленным образом Astra Linux Common Edition «Орёл» 2.12.22; задание уточнено для подготовки и выполнения на этом выпуске. Тема соответствует практической работе № 7 раздела 4.2 РПД 10.05.01: разрешённая инвентаризация собственной Astra с Kali, сопоставление портов с процессами и анализ избыточных сервисов.

Актуальное студенческое задание: [Lab07.md](Lab07.md). Полный переносимый комплект: [архив](Практическая_7_Орел_комплект.zip). Исходная редакция сохранена отдельно: [оригинал](materials/Lab07_до_адаптации_Орел.md).

## Что проверено и изменено

Проверен именно локальный `orel-current.iso`: его внутреннее описание — `OS Astra Linux 2.12.22 orel - amd64 DVD`. Имя файла не означает, что это современный последний выпуск. Прочитаны индексы пакетов и содержимое DEB; SHA256 каждого из 12 исследованных пакетов совпал с индексом носителя. Это подтверждает наличие пакетов на ISO, но не их установку в конкретной VM.

| Средство | Версия на ISO | Результат |
|---|---|---|
| iproute2 | 4.9.0-1+deb9u1 | Фильтры `ss` по sport поддерживаются; для адресов выбран обычный `ip -4 address show` |
| Python | 3.5.3 | В реальном исходнике http.server есть `--bind`; каталог задаётся через cd, без более нового --directory |
| systemd | 232-25+deb9u11astra.ce1 | Справка подтверждает `systemctl status PID`; пользовательский сервер может принадлежать scope |
| curl | 7.52.1-5+deb9u9 | Справка содержит --noproxy; сохранены ограничения времени запросов |
| Bash / coreutils | 4.4-5 / 8.26-3 | Используется штатный синтаксис и GNU-утилиты |
| procps / findutils / diffutils | 3.3.12 / 4.6.0 / 3.5 | Пакеты присутствуют на носителе |

Nmap нужен на Kali, устанавливать его на Astra не требуется. PARSEC и модули мандатного доступа в этой работе не используются. Метод TCP connect и трактовки состояний сверены с [официальным справочником Nmap](https://nmap.org/book/man-port-scanning-techniques.html) и [обзором состояний портов](https://nmap.org/book/port-scanning.html). Правила выбора источников пакетов сверены с [документацией Astra](https://docs.astralinux.ru/latest/guide/compound/repo/add_install/); её современные примеры URL не подставлялись в старый выпуск.

Добавлены предварительная проверка зависимостей и Python --bind, временный NAT на единственном адаптере с DHCP, установка из совместимого источника и вариант установки с ISO. Возврат Internal Network, статических адресов, пустых шлюза/DNS и отсутствие default route в IPv4/IPv6 стали обязательными условиями начала эксперимента. Подготовка пакетов выполняется до 90 минут занятия.

Уточнён завершённый снимок выключенной Astra, защищён запуск HTTP после cd, исправлены нумерация и ссылки на таблицы. Учтён случай, когда завершённый Nmap выводит общую сводку одинаковых состояний вместо отдельных строк портов. Приложена точная копия ПР1 с изображениями; устранена зависимость задания от внешних файлов репозитория. Сохранены 27 вариантов, ограничения сканирования, действующие firewall и штатные службы.

## Фактически выполненная проверка

202 проверки прошли: синтаксис 22 Bash-блоков через bash -n, 27 вариантов и их адресов/портов, внутренние переходы и локальные ссылки задания, ресурсы ПР1, целостность ZIP и совпадение его файлов с итоговыми материалами. Подробности: [validation.json](materials/validation.json), [пакетные доказательства](materials/orel_package_evidence.json).

Исходный HTTP-обработчик Python 3.5, извлечённый из пакета ISO, разобран как синтаксис Python 3.5 и дополнительно выполнен на Windows/Python 3.11: локальный запрос к 127.0.0.1 вернул HTTP 200 и учебную страницу. Это проверка старого обработчика под другим интерпретатором, а не запуск Python 3.5 или гостевой Astra.

На целевых Astra/Kali VM работа не запускалась. Не проверены фактическая установка пакетов в VM, доступность её репозитория, действия графического менеджера сети и результаты сканирования через Internal Network с её firewall. Для преподавательского прогона остаются: подготовка по разделу 2.2 и один полный вариант до/во время/после с сохранением доказательств. Действующая фильтрация P допустима и не требует отключать защиту.
