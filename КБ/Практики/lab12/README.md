# Практическая работа № 12

[Задание](Lab12.md): усиление SSH на Astra Linux «Орёл» 2.12.22 (OpenSSH 7.4), 27 вариантов, 90 минут. Начните с проверки комплекта, режима сети и снимка; все изменения SSH выполняются из локальной консоли Astra. Настраивается настоящий `/etc/ssh/sshd_config`: блок усиления, ограничение по группе, вход только по ключу, отключение пересылок и слабых алгоритмов, по варианту — запрет или ограничение второй записи блоком Match. Результат подтверждается `sshd -T`, семью контрольными подключениями с Kali и журналом; в конце конфигурация восстанавливается и сверяется по хешу. Исходный стенд — в [ПР1](reference/Lab1.md).

Состав: `tools/pr12.py` (Astra), `tools/pr12_probe.py` (Kali), `SHA256SUMS.txt`. Комплект целиком копируется на обе VM в `$HOME/pr12/kit`.
