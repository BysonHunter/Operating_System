# Практическая работа № 11

[Задание](Lab11.md): проверка уязвимостей конфигурации и обновлений для «Орла» 2.12.22, 27 вариантов, 90 минут. Начните с проверки комплекта и режима сети. Kali выполняет ограниченное сканирование одного порта своей Astra; находки подтверждаются локально; обновляется учебный пакет pr11-demo из локального репозитория, подписанного учебным ключом. Штатные пакеты Astra только проверяются по версиям. Комплект целиком копируется на обе VM в `$HOME/pr11/kit`; исходный стенд — в [ПР1](reference/Lab1.md).

Состав: `tools/pr11.py` (Astra), `tools/pr11_check.py` (Kali), `repo/` (доверенный репозиторий, посторонний источник, открытый ключ, подписанный бюллетень), `src/` (исходник службы и сборка репозитория для преподавателя), `SHA256SUMS.txt`.

Отпечаток учебного ключа: `5DFE 8889 5F0C 7932 597E  6B4D 770F AA1F BFFF 93BE`. Закрытые ключи в комплект не входят. Для пересборки репозитория со своим ключом выполните `src/build_repo.py` и замените отпечаток в `tools/pr11.py` (TRUSTED_FPR), Lab11.md и этом файле.
