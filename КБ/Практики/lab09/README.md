# Практическая № 9: модель мандатного доступа на «Орле»

Начните с [задания](Lab09.md), затем откройте [свой вариант](Варианты.md). Номер варианта — номер по журналу, всего 27. [Справочная копия практической № 1](reference/Lab1.md) включена вместе с исходными изображениями.

Распакуйте содержимое учебного архива непосредственно в `~/oslab/lab09`. Запускайте `python3 mac_model.py` обычным пользователем. Нужен Python не ниже 3.5 со стандартной библиотекой; pip и внешние модули не требуются. Проверка зависимостей, установка с доверенного ISO или через временный NAT/DHCP, возврат изолированной сети описаны в начале задания.

**Это учебная программная модель, не PARSEC.** Она не защищает реальные файлы от владельца хранилища, не аутентифицирует логических субъектов и не создаёт системный аудит. Эти ограничения проверяются в обязательном опыте.

Основные файлы: `mac_model.py` — модель и CLI; `Lab09.md` — задание; `Варианты.md` — 27 вариантов; `SHA256SUMS` — контрольные суммы выданных файлов. Рабочие policy.json, objects.json, predictions.csv и audit.jsonl создаются командой init в новом каталоге. Серия suite добавляет results.csv. При повторном опыте создавайте новый каталог; старые результаты не перезаписываются.

Версия комплекта 1.0, 25.10.2026. Модель использует упрощённые правила Bell–LaPadula с фиксированными метками объектов. Это не точное воспроизведение всех правил Astra Linux SE, DAC, МКЦ, контейнеров и привилегий.
