# Практическая № 6 для Astra Linux «Орёл»

Откройте [задание](Практическая_6_Аутентификация.md). Оно рассчитано на CE 2.12.22 со штатными PAM 1.1.8, pam_tally2 и pwquality 1.3.0. Это нативный опыт с PAM/SSH, не моделирование. Внутри — 27 вариантов, проверка зависимостей, установка ISO/NAT с возвратом изоляции, парольные тесты, блокировка и восстановление.

[Справочная копия работы № 1](reference/Lab1.md) включена с изображениями. Для проверки комплекта выполните `sha256sum -c SHA256SUMS_Орел` из распакованной папки. Пароли и реальные пользовательские данные в комплект не входят.

Перед выполнением нужен завершённый снимок выключенной VM, локальная административная консоль и подготовленная пара Astra/Kali. Применяется только временная запись своего варианта. Подробные условия — в начале задания.
