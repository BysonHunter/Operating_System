# Лекция 2. Архитектуры ОС и системные вызовы

Комплект по дисциплине «Операционные системы», специальность 10.05.01 «Компьютерная безопасность».

- PPTX: 40 слайдов с заметками докладчика. Текст и таблицы редактируются в PowerPoint.
- DOCX и Markdown: полный теоретический конспект, 17 иллюстраций, 4 таблицы, вопросы и глоссарий.
- Текст_озвучки_лекции_2.md: 40 фрагментов, совпадающих с заметками PPTX.
- images/: 17 прозрачных рисунков PNG в оттенках серого, 2880 × 1180.
- Исходники_рисунков_SVG/: редактируемые векторные исходники рисунков.
- План_лекции_2_и_слайдов.md: последовательность, точный текст, описание композиции и источники.

Для видеолекции импортируйте PPTX и сопоставьте слайду N раздел «Слайд N» из текста озвучки. Если сервис импортирует заметки докладчика, отдельное копирование текста не требуется. Заголовки Markdown не озвучиваются. Голос, паузы и синхронизация настраиваются в выбранном видеосервисе.

90 минут — продолжительность занятия с разбором примеров и обсуждением; объём отдельной озвучки указан в её файле. Готовая аудиозапись и видео в комплект не входят.
