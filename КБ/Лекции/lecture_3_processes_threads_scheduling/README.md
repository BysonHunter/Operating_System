# Лекция 3. Процессы, потоки и управление процессами

Переработанный комплект по дисциплине «Операционные системы», 10.05.01 «Компьютерная безопасность», 3-й курс. Продолжительность аудиторного занятия — 90 минут.

- **Лекция_3_Процессы_потоки_с_озвучкой.pptx** — 48 слайдов, текст озвучки в заметках каждого слайда.
- **Лекция_3_Процессы_потоки_обновленная.docx** — полный иллюстрированный конспект, 30 страниц, 28 схем и 8 таблиц.
- **Лекция_3_Процессы_потоки_и_управление_процессами.md** — тот же теоретический материал с оглавлением, относительными ссылками на рисунки, вопросами и глоссарием.
- **Текст_озвучки_лекции_3.md** — реплики по номерам слайдов.
- **Озвучка_по_слайдам/** — 48 файлов TXT с репликами без заголовков.
- **images/** — 28 рисунков PNG, оттенки серого, прозрачный фон, 2880 × 1180.
- **Исходники_рисунков_SVG/** — 28 векторных исходников для редактирования.
- **План_лекции_3_и_слайдов.md** — учебный смысл, готовый текст, описание рисунков, компоновка и связь с конспектом.
- **Карта_источников_лекции_3.md** — технические первоисточники по слайдам.
- **Сведения_для_преподавателя.md** — изменения, состояние комплекта и результаты проверки.

Текст и таблицы PPTX редактируются. Четыре временные шкалы FCFS/SJF/SRTF/RR также собраны из редактируемых объектов с точным масштабом времени. Остальные схемы встроены как изображения; для их изменения приложены SVG. Содержание заметок относится к информации соответствующего слайда.

## Подготовка видеолекции

Каждому слайду N соответствует раздел «Слайд N» сценария и файл N.txt. Если сервис поддерживает заметки докладчика, импортируйте их напрямую. При ручной вставке берите только реплику, без заголовка. Начальный ориентир темпа — 120–140 слов в минуту. После переходов состояний, формул и выбора очередной задачи полезны смысловые паузы; проверьте произношение сокращений в голосовом движке.

90 минут — занятие с обсуждением и расчётами. Компактная озвучка занимает примерно 27–31 минуту без дополнительных пауз. Готовые звук и видео не входят в комплект. Итоговую синхронизацию проверяют после генерации речи в выбранном сервисе.

Для чтения MD распакуйте весь архив, сохранив папку images рядом с файлом. SHA256SUMS.txt содержит контрольные суммы файлов комплекта.
