# Лекция 1. Операционная система как объект защиты

Версия 2.0 от 05.11.2026. 36 слайдов и 17 перерисованных иллюстраций.

- PPTX содержит отдельный текст озвучки каждого слайда в заметках докладчика.
- «Текст_озвучки_лекции_1.md» содержит те же фрагменты для видеосервиса.
- Конспект сохраняет полный теоретический материал, содержит новые рисунки и оглавление.
- План содержит текст, компоновку, описание и подписи рисунка каждого слайда.
- images: прозрачные PNG в оттенках серого. «Исходники_рисунков_SVG»: векторные исходники.

Для видео сохраняйте соответствие номера слайда и фрагмента озвучки. Если сервис не читает заметки PPTX, перенесите текст из отдельного MD. Сценарий содержит 2506 слов. 90 минут относятся к аудиторному занятию с объяснениями, демонстрациями и обсуждением. Длительность видео зависит от темпа речи и пауз.
